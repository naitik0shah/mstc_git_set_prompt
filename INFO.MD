## Initial Prompt

```text
Create a complete playable Space Shooter game website using only HTML, CSS, and vanilla JavaScript.

Requirements:

1. TECHNOLOGY
- Use HTML5 for the structure.
- Use CSS3 for all styling and animations.
- Use vanilla JavaScript for all game logic.
- Do not use React, Vue, Bootstrap, Tailwind, or any external framework.
- The game must run directly in a browser.

2. GAMEPLAY
- The player controls a spaceship at the bottom of the screen.
- Move the spaceship using:
  - Left Arrow / A
  - Right Arrow / D
- Shoot using:
  - Spacebar
- Enemies should appear from the top and move downward.
- Destroying an enemy gives points.
- If an enemy reaches the bottom, the player loses health.
- The game ends when health reaches zero.
- Add multiple enemy types with different speeds and health.
- Add power-ups such as:
  - Rapid Fire
  - Shield
  - Double Score
- Make the game progressively harder as the score increases.

3. UI
Create a modern gaming interface containing:
- Game title
- Score
- High Score
- Health bar
- Current level
- Start Game button
- Pause button
- Restart button
- Game Over screen
- Final score display

4. VISUAL DESIGN
- Use a dark space-themed background.
- Add stars in the background using CSS or JavaScript.
- Use glowing neon colors.
- Add smooth animations.
- Add particle/explosion effects when enemies are destroyed.
- Make the interface look like a professional arcade game.
- Add hover and click animations to buttons.
- Make the game responsive for desktop and mobile screens.

5. AUDIO
Use JavaScript to create simple game sound effects if possible.
Include sounds for:
- Shooting
- Enemy destruction
- Power-up collection
- Game over

Do not require external audio files; use the Web Audio API if possible.

6. GAME MECHANICS
Implement:
- Collision detection
- Player movement
- Bullets
- Enemies
- Enemy spawning
- Enemy health
- Power-ups
- Score system
- High-score storage using localStorage
- Levels
- Increasing difficulty
- Pause/resume functionality
- Game-over functionality
- Restart functionality

7. MOBILE CONTROLS
On mobile devices, display touch controls:
- Left button
- Right button
- Shoot button

8. CODE QUALITY
- Keep the code clean and well organized.
- Add comments explaining important sections.
- Avoid unnecessary libraries.
- Make sure there are no console errors.
- Make the game fully playable immediately after opening the HTML file.

9. FILE STRUCTURE
Provide the project as:

index.html
style.css
script.js

Explain exactly where each piece of code should be placed.

10. IMPORTANT
Do not give me a basic demo.
Create a polished, fun, visually impressive browser game with complete gameplay.
```
